The role

I worked across the React front end, the Java API behind it and the MySQL database underneath. I was also on a coding bootcamp alongside the job.

The problems

Pages took too long to load. Some modules were still in PHP and had to move to Spring Boot. Layouts and features broke on some phones and browsers, and a key API was slower than it needed to be.

Decisions

  • Make the front end do less up front.We refactored React components and lazy-loaded assets, so a page loads what it needs first.
  • Move PHP to Spring Boot in pieces.Migrating module by module let us release in smaller steps. I wrote endpoints, validation and tests, and fixed defects along the way.
  • Test across browsers, then fix.A cross-browser testing pipeline caught the mobile layout and functionality bugs, and I fixed them.
  • Measure the database.We added indexes and rewrote slow queries, starting with the API that mattered most.

What changed

Cloud costs fell by 18%.

What I took with me

Alongside the job I did freelance AI training, reviewing 1,000 code items across TypeScript, Python, Java, C# and SQL at 97% QA precision. It was my first sustained work with AI on code, and the start of the thread that leads to the workflow I built at BNP Paribas.
